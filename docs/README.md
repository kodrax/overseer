# overseer documentation

overseer is a requirements registry and Agile board for coding agents. Pick the path that fits you.

## Start here

New to coding agents? Read these in order; each page ends with a link to the next.

1. [Getting started](getting-started.md): install, turn overseer on in a project, and a first run of about five minutes.
2. [Concepts](concepts.md): harness, MCP, skills and the subagent; requirements, stories, coverage and the rest of the data model.
3. [Web board](board.md): the registry in your browser.
